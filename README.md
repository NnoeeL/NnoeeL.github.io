## 🛠️ Bahasa & Teknologi yang Digunakan

Website ini dibangun secara murni (*vanilla*) tanpa framework berat atau build tools yang rumit, sehingga memiliki performa yang sangat ringan dan cepat diakses:

1. **HTML5 (HyperText Markup Language)**
   - Struktur semantik (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
   - Meta tag SEO lengkap dan Open Graph protocol untuk pratinjau tautan (*link preview*) di WhatsApp, Telegram, dan media sosial.

2. **CSS3 (Cascading Style Sheets)**
   - Variabel CSS kustom (*CSS Custom Properties*) untuk manajemen palet warna bertema dark terminal (slate, emerald, cyan, neon purple).
   - Flexbox dan CSS Grid untuk layout kartu proyek dan keahlian yang sepenuhnya responsif (desktop, tablet, mobile).
   - Efek transisi halus, glow neon, custom scrollbar, dan animasi interaktif.

3. **JavaScript (Vanilla ES6+)**
   - Efek pengetikan teks dinamis (*typewriter effect*) pada hero section.
   - Rendering dinamis data proyek dan skill dari objek data terstruktur.
   - Sistem filter kategori proyek interaktif.
   - Toggle navigasi mobile burger menu.
   - Fitur salin alamat email ke clipboard secara instan dengan notifikasi umpan balik (*toast feedback*).
   - Scroll reveal animation untuk efek elemen muncul saat digulir.

4. **Pustaka & Aset Pendukung:**
   - **Google Fonts:** *JetBrains Mono* (nuansa monospace terminal/kode) & *Plus Jakarta Sans* (tipografi sans-serif modern).
   - **Font Awesome 6 (CDN):** Koleksi ikon antarmuka dan logo teknologi yang ringan.
